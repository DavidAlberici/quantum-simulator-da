# Requirimientos 
- Python 3.12+  
- Packages: `pip install -r requirements.txt` 

# Información general
Solo son necesarios los ficheros gates, main y qregistry. El fichero test_qregistry contiene
tests unitarios (y algun otro tipo de test). En el fichero main se muestran algunos casos
de uso tipicos, cubiertos por este simulador.

## Coste computacional
Se incluye un fichero markdown "computational_cost" con el cálculo de dicho
coste para los metodos publicos de la clase QRegistry
